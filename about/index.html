About Roman Böhm

Roman Böhm is a software engineer living in Würzburg, Germany. He is mostly interested in Java, the JVM, the Spring framework, RDBMs, and producing boring yet stable software.

As of 2025, Roman is working at Scalable Capital.

Previously, he worked at Flyeralarm and Spread Group.

Roman’s side projects include

  • JSON Wheel: a tiny, hackable JSON deserializer for the JVM
  • wichtelnng, a secret santa tech demo showing off recent Java and Spring Boot
  • dupleasure, a web application to reorder PDF docs as if they’d been duplex scanned
